# RTMPose-s (body7, 256x192)

`rtmpose-s-body7.onnx` is the ONNX export of RTMPose-s from OpenMMLab MMPose
(https://github.com/open-mmlab/mmpose/tree/main/projects/rtmpose), released under the Apache License 2.0.
`rtmpose-m-hand.onnx` is RTMPose-m (hand, 21 keypoints, 256x256) from the same project, same licence.

Used offline for "pose from photo"; no data leaves the computer.
