# MakeHuman assets

`body.bin.gz` is packed from the MakeHuman 1.x base mesh, default skeleton, default skin weights and macro
targets (https://github.com/makehumancommunity/makehuman), all released under CC0 1.0 by the MakeHuman team.
Regenerate with `python -I tools/mh_convert.py <makehuman/data> assets/makehuman/body.bin.gz`.
